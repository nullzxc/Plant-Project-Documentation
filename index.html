Smart Plant Watering with Soil Moisture Sensor & Relay Pump

Raspberry Pi reads soil moisture (GPIO IN) and drives a mini-pump through a relay (GPIO OUT). Tkinter GUI lets users calibrate thresholds, view live moisture and logs, and toggle manual watering.

Project Snapshot

  • Goal: Keep plant soil within a healthy moisture range automatically.
  • Inputs: Soil moisture sensor (digital or via ADC → GPIO), GUI controls.
  • Outputs: Relay-driven pump/valve, status LED/buzzer.
  • Language: Python 3 + Tkinter.
  • Device: Raspberry Pi 4 (GPIO).

System Architecture

High-level data flow:

Soil Sensor (analog) → ADC (e.g., MCP3008) → Pi GPIO (SPI) → Python Logic →
                                                   ├─ Tkinter GUI (thresholds/logs)
                                                   └─ Relay (BCM 23) → Pump + 5V Supply

Optional: LED (BCM 24) for status, Buzzer (BCM 18) for alerts.

Control Logic (pseudo)

if moisture < DRY_THRESHOLD and cooldown_elapsed:
  turn_pump_on for PUMP_SECONDS
elif moisture >= WET_THRESHOLD:
  ensure pump_off
log reading every SAMPLE_SECONDS; show in GUI chart/log

Starter Code (GPIO + Tkinter)

# file: app.py
# Minimal example: digital sensor + relay + Tkinter GUI
import time, threading
import RPi.GPIO as GPIO
import tkinter as tk

BCM_RELAY = 23
BCM_SENSOR = 25  # digital output from sensor module
PUMP_SECONDS = 3
SAMPLE_SECONDS = 2

GPIO.setmode(GPIO.BCM)
GPIO.setup(BCM_RELAY, GPIO.OUT, initial=GPIO.HIGH)  # HIGH=off on many modules
GPIO.setup(BCM_SENSOR, GPIO.IN, pull_up_down=GPIO.PUD_UP)

class App:
    def __init__(self, root):
        self.root = root
        root.title("Plant Watering System")
        self.moisture_label = tk.Label(root, text="Moisture: —", font=("Segoe UI", 16))
        self.moisture_label.pack(pady=8)
        self.threshold = tk.IntVar(value=0)  # 0=dry on digital sensors
        tk.Button(root, text="Manual Water", command=self.water_now).pack(pady=4)
        self.log = tk.Text(root, height=8, width=48)
        self.log.pack(pady=8)
        self.running = True
        threading.Thread(target=self.loop, daemon=True).start()

    def read_moisture(self):
        # Digital sensors: 0=dry, 1=wet (often)
        val = GPIO.input(BCM_SENSOR)
        return val

    def set_pump(self, on):
        # Many relay boards are active LOW
        GPIO.output(BCM_RELAY, GPIO.LOW if on else GPIO.HIGH)

    def water_now(self):
        self.append("Manual watering…")
        self.set_pump(True); time.sleep(PUMP_SECONDS); self.set_pump(False)
        self.append("Pump off.")

    def append(self, msg):
        self.log.insert(tk.END, time.strftime("[%H:%M:%S] ") + msg + "\\n")
        self.log.see(tk.END)

    def loop(self):
        while self.running:
            m = self.read_moisture()
            self.root.after(0, self.moisture_label.config, {"text": f"Moisture: {'WET' if m else 'DRY'} ({m})"})
            if m == self.threshold.get():
                self.append("Soil dry → watering")
                self.set_pump(True); time.sleep(PUMP_SECONDS); self.set_pump(False)
                self.append("Pump off.")
            time.sleep(SAMPLE_SECONDS)

    def close(self):
        self.running = False
        self.set_pump(False)
        GPIO.cleanup()

if __name__ == "__main__":
    try:
        root = tk.Tk(); app = App(root)
        root.protocol("WM_DELETE_WINDOW", lambda: (app.close(), root.destroy()))
        root.mainloop()
    finally:
        GPIO.cleanup()

Tip: If your sensor is analog-only, replace read_moisture() with an MCP3008 SPI read and compare to a threshold slider in the GUI.

# Control parameters
PUMP_SECONDS = 4         # pump ON time per cycle
SAMPLE_SECONDS = 2       # read interval
COOLDOWN_SECONDS = 600   # min gap between auto-watering cycles

# For analog mode (MCP3008)
SPI_BUS = 0
SPI_DEVICE = 0
MCP3008_CHANNEL = 0      # CH0
DRY_THRESHOLD = 450      # tune by calibration (0..1023)
WET_THRESHOLD = 700      # if using hysteresis

# Relay logic (many boards are active LOW)
RELAY_ACTIVE_LOW = True

mcp3008_helper.py

import spidev

class MCP3008:
    def __init__(self, bus=0, device=0):
        self.spi = spidev.SpiDev()
        self.spi.open(bus, device)
        self.spi.max_speed_hz = 1350000

    def read(self, channel=0):
        assert 0 <= channel <= 7
        # SPI transaction: start bit, single-ended, channel bits
        r = self.spi.xfer2([1, (8 + channel) << 4, 0])
        value = ((r[1] & 3) << 8) | r[2]
        return value

    def close(self):
        try:
            self.spi.close()
        except Exception:
            pass

app_digital.py (GUI for digital sensor) 

import time, threading
import RPi.GPIO as GPIO
import tkinter as tk
import config

GPIO.setmode(GPIO.BCM)

# Setup pins
GPIO.setup(config.BCM_RELAY, GPIO.OUT, initial=GPIO.HIGH if config.RELAY_ACTIVE_LOW else GPIO.LOW)
GPIO.setup(config.BCM_SENSOR_DIGITAL, GPIO.IN, pull_up_down=GPIO.PUD_UP)
try:
    GPIO.setup(config.BCM_LED, GPIO.OUT)
except Exception:
    pass

last_auto = 0

def relay(on: bool):
    # active LOW handling
    level = GPIO.LOW if (on == config.RELAY_ACTIVE_LOW) else GPIO.HIGH
    GPIO.output(config.BCM_RELAY, level)
    try:
        GPIO.output(config.BCM_LED, GPIO.HIGH if on else GPIO.LOW)
    except Exception:
        pass

class App:
    def __init__(self, root):
        self.root = root
        root.title("Plant Watering – Digital")
        self.state = tk.StringVar(value="—")
        self.cooldown = config.COOLDOWN_SECONDS
        self.running = True

        tk.Label(root, textvariable=self.state, font=("Segoe UI", 18)).pack(pady=6)
        tk.Button(root, text="Water Now", command=self.water_now).pack(pady=4)
        self.log = tk.Text(root, height=10, width=56); self.log.pack(pady=8)

        threading.Thread(target=self.loop, daemon=True).start()

    def logmsg(self, s):
        self.log.insert(tk.END, time.strftime("[%H:%M:%S] ") + s + "\\n"); self.log.see(tk.END)

    def read_digital(self):
        # typical modules: 0=dry, 1=wet (verify yours!)
        return GPIO.input(config.BCM_SENSOR_DIGITAL)

    def water_now(self):
        self.logmsg("Manual watering…")
        relay(True); time.sleep(config.PUMP_SECONDS); relay(False)
        self.logmsg("Pump off.")

    def loop(self):
        global last_auto
        while self.running:
            wet = self.read_digital()  # 1=wet, 0=dry (common)
            self.root.after(0, self.state.set, f"Moisture: {'WET' if wet else 'DRY'} ({wet})")
            now = time.time()
            if (not wet) and (now - last_auto >= self.cooldown):
                self.logmsg("Auto: DRY detected → watering")
                relay(True); time.sleep(config.PUMP_SECONDS); relay(False)
                last_auto = now
                self.logmsg("Auto: done")
            time.sleep(config.SAMPLE_SECONDS)

    def close(self):
        self.running = False
        relay(False)
        GPIO.cleanup()

if __name__ == "__main__":
    try:
        root = tk.Tk(); app = App(root)
        root.protocol("WM_DELETE_WINDOW", lambda: (app.close(), root.destroy()))
        root.mainloop()
    finally:
        GPIO.cleanup()

app_analog.py (GUI for MCP3008 analog) 

import time, threading
import RPi.GPIO as GPIO
import tkinter as tk
import config
from mcp3008_helper import MCP3008

GPIO.setmode(GPIO.BCM)
GPIO.setup(config.BCM_RELAY, GPIO.OUT, initial=GPIO.HIGH if config.RELAY_ACTIVE_LOW else GPIO.LOW)
try:
    GPIO.setup(config.BCM_LED, GPIO.OUT)
except Exception:
    pass

adc = MCP3008(config.SPI_BUS, config.SPI_DEVICE)
last_auto = 0

def relay(on: bool):
    level = GPIO.LOW if (on == config.RELAY_ACTIVE_LOW) else GPIO.HIGH
    GPIO.output(config.BCM_RELAY, level)
    try:
        GPIO.output(config.BCM_LED, GPIO.HIGH if on else GPIO.LOW)
    except Exception:
        pass

class App:
    def __init__(self, root):
        self.root = root
        root.title("Plant Watering – Analog (MCP3008)")
        self.value = tk.IntVar(value=0)
        self.thresh = tk.IntVar(value=config.DRY_THRESHOLD)
        self.running = True

        row = tk.Frame(root); row.pack(pady=6)
        tk.Label(row, text="Moisture:").pack(side=tk.LEFT)
        tk.Label(row, textvariable=self.value, font=("Segoe UI", 16)).pack(side=tk.LEFT, padx=8)

        tk.Scale(root, from_=0, to=1023, orient=tk.HORIZONTAL, variable=self.thresh,
                 label="Dry Threshold", length=320).pack(padx=10, pady=6)
        tk.Button(root, text="Water Now", command=self.water_now).pack(pady=4)
        self.log = tk.Text(root, height=10, width=56); self.log.pack(pady=8)

        threading.Thread(target=self.loop, daemon=True).start()

    def logmsg(self, s):
        self.log.insert(tk.END, time.strftime("[%H:%M:%S] ") + s + "\\n"); self.log.see(tk.END)

    def read_value(self):
        return adc.read(config.MCP3008_CHANNEL)

    def water_now(self):
        self.logmsg("Manual watering…")
        relay(True); time.sleep(config.PUMP_SECONDS); relay(False)
        self.logmsg("Pump off.")

    def loop(self):
        global last_auto
        while self.running:
            v = self.read_value()
            self.root.after(0, self.value.set, v)
            now = time.time()
            if v < self.thresh.get() and (now - last_auto >= config.COOLDOWN_SECONDS):
                self.logmsg(f"Auto: value={v} < threshold → watering")
                relay(True); time.sleep(config.PUMP_SECONDS); relay(False)
                last_auto = now
                self.logmsg("Auto: done")
            time.sleep(config.SAMPLE_SECONDS)

    def close(self):
        self.running = False
        relay(False)
        try: adc.close()
        except Exception: pass
        GPIO.cleanup()

if __name__ == "__main__":
    try:
        root = tk.Tk(); app = App(root)
        root.protocol("WM_DELETE_WINDOW", lambda: (app.close(), root.destroy()))
        root.mainloop()
    finally:
        GPIO.cleanup()

README.md (snippet)

# Plant Watering System (Raspberry Pi)

## Quick Start
1. Enable SPI (if using MCP3008): `sudo raspi-config` → Interface → SPI → Enable
2. Install deps: `sudo apt install -y python3-tk && pip3 install RPi.GPIO spidev`
3. Wire relay, sensor, and common ground; use separate 5V for pump.
4. Digital sensor: `python3 app_digital.py`  •  Analog+MCP3008: `python3 app_analog.py`

## Safety
- Separate pump supply; never power motor from Pi 5V
- Common ground between Pi, relay logic, sensor, pump supply
- Max ON time + cooldown in `config.py`

Testing, Stability & Logs

  • GPIO directions, relay logic (active LOW/HIGH), sensor polarity.
  • Stress: 50+ on/off cycles; ensure pump supply doesn’t brown-out the Pi.
  • Safety: separate 5V pump supply; common ground; optional flyback if transistor driving.
  • GUI: threshold updates, manual override, log scroll.

Safety & Reliability

  • Use a separate 5V supply for the pump. Share common ground with the Pi.
  • Keep electronics above water line; drip loops; avoid spills near the Pi.
  • Start with pump disconnected; confirm relay logic (active LOW/HIGH) first.
  • Enforce max pump-on time and cooldown in software.

Build & Test Checklist

  • Pi updated; Python deps installed; SPI enabled if needed.
  • Relay clicks on command; sensor readings sensible (air/dry/wet distinct).
  • Pump runs via relay on separate 5V; Pi stays stable (no brown-outs).
  • GUI: live moisture, manual button, logs; threshold slider (analog).
  • Stability: 30–50 auto cycles; photos & screenshots captured.

FAQ / Troubleshooting

Relay always on? Your board might be active-LOW. Flip logic with RELAY_ACTIVE_LOW = True.

Pi reboots when pump starts? The pump must have its own 5V supply; only grounds are shared.

Sensor reads backwards? Digital modules vary: sometimes 0=dry, 1=wet. Test in air/water to confirm.

No analog values? Enable SPI and check MCP3008 wiring; verify SPI_BUS/DEVICE.
