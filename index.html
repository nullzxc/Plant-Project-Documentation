Hardware Setup

The system is designed for the Raspberry Pi 4 Model B. It utilizes standard GPIO pins for digital I/O.

Moisture Sensor (GPIO 16)

Digital input. Sends HIGH signal when soil is dry.

5V Relay & Pump (GPIO 20)

Active LOW logic. Controls external 5V power to the pump.

Status LEDs (GPIO 5, 6, 13)

Visual feedback for system status and active recording.

⚡ Power Safety: Never power the pump directly from the Raspberry Pi 5V pin. Use an external power supply and a common ground.

def auto_watering_loop():
    isDry = False
    print("Auto-Watering is starting...")
    
    while not stop_watering.is_set():
        # Check Digital Sensor
        if GPIO.input(SENSOR_PIN) == GPIO.HIGH:
            isDry = True
        
        if isDry:
            print("Watering plant...")
            GPIO.output(PUMP_PIN, GPIO.LOW)
            sleep(1)
            GPIO.output(PUMP_PIN, GPIO.HIGH)
            
        sleep(WATERING_INTERVAL)
